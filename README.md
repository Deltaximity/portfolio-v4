My personal portfolio showcasing my work, thought process, and unique style as a fullstack developer.
Built with Next.js 15, TypeScript, Sass and Framer Motion, with a custom design system inspired by retro and nature aesthetics 🌿.

### Tech Stack
- Framework: [Next.js 15](https://nextjs.org/)
- Language: [TypeScript](https://www.typescriptlang.org/)
- Styling: [Sass](https://sass-lang.com/)
- CMS: Markdown + custom file system
- Animations: [Motion](https://motion.dev/) + custom CSS
